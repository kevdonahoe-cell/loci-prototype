# Memory Castle (prototype)

A phone-first web app that teaches the memory-palace method (method of loci). You paste your own text, choose a familiar route, make your own vivid images, then practise with simple spaced repetition.

- Plain HTML, CSS and JavaScript. No accounts, no server, no tracking.
- All data is stored on your device (localStorage). Use "Back up" to save a JSON copy.
- Installable as a home-screen app (PWA).
- The Beatitudes example contains only short cue titles. It does not include any copyrighted Bible text; users paste their own copy.

Prototype only. Run locally with any static server, e.g. `python3 -m http.server`.

## Version 0.2
- **Smarter splitting** (`splitter.js`): numbered and verse-numbered text, lines, sentences, repeated openers such as "Happy are those who...: they shall..." (even with no punctuation), and long paragraphs cut at sentences, semicolons, colons and commas. A preview screen shows the proposed pieces before the castle is built, with Smaller / Balanced / Bigger.
- **Image ideas in words** (`ideas.js`): three local template ideas per stop. Nothing is generated by a server or AI, and the learner writes the image.
- **Session notes** (`notes.js`): "Something confused me" on every screen, and "Share session notes" to export only those notes and the screen trail. Never includes text, images, stop or route names. Stored separately from castles and not part of backups.

Checks: `node test-sr.js && node test-split.js && node test-ideas-notes.js`; the phone-viewport run is `e2e.js` (see header). All sample text in tests is invented.
